# Карелия: между скалами и озёрами

Версия 5 — 22.10.2026. Повторно проверены карточки, маршруты, фотографии, источники и ссылки. Обложка — мраморный каньон Рускеала.

Версия 4: На карте добавлена динамическая метрическая линейка масштаба.

Версия 3: Добавлены схема связей между остановками маршрутов, публичная библиография и ссылки на готовые программы. Из интерфейса убраны упоминания исходного файла.

Готовый адаптивный путеводитель на чистых HTML/CSS/JavaScript + Leaflet 1.9.4. Сборка, npm и ключи API не нужны.

## Быстрый запуск

1. Распакуйте архив и откройте папку `karelia`.
2. Для локального просмотра запустите в этой папке:

   ```sh
   python3 -m http.server 8080
   ```

3. Откройте http://localhost:8080 в современном браузере (Chrome, Firefox, Edge, Safari).

В Windows команда может называться `py -m http.server 8080`. Простое открытие `index.html` также не требует fetch для данных или фотографий, но рекомендован HTTP-сервер: поведение карт и ссылок при `file://` различается между браузерами. Нельзя открывать сайт внутри ZIP — сначала распакуйте.

## GitHub Pages

1. Создайте репозиторий в GitHub.
2. Загрузите **содержимое** папки `karelia` в корень репозитория: `index.html` должен лежать в корне, рядом с `style.css`, `app.js`, `data.js`, `credits.js` и `assets/`.
3. В Settings → Pages → Build and deployment выберите Deploy from a branch, ветку `main`, папку `/ (root)` и Save.
4. После завершения публикации откройте адрес из раздела Pages: `https://USERNAME.github.io/REPOSITORY/`.

Все внутренние пути относительные: проект работает и в подпапке репозитория. Файл `.nojekyll` включён. Никакие секреты и серверная часть не нужны. GitHub Pages в рамках этой работы не публиковался; готовые файлы предоставлены для размещения пользователем.

## Что есть на сайте

- 10 проверенных справочных точек WGS84, нумерованные маркеры трёх категорий и группировка близких точек (нажмите группу для увеличения), управление масштабом и кнопка «Все точки».
- Синхронизация списка с маркерами, поиск по названию, региону и типу места; `ё` и `е` равноценны. Клавиша `/` переводит фокус в поиск.
- Подробные карточки: галерея из четырёх локальных фотографий, два абзаца из путеводителя, факт, сезонность, время посещения, цена при наличии, источники и координаты.
- Карточки открываются и из списка, и с карты; закрываются крестиком и Escape. Диалог удерживает фокус, после закрытия возвращает его в список. Прямая ссылка: `index.html#place-kizhi`.
- Три региональные идеи поездок с показом точек и схематических линий. Зелёные линии — наземные связи, синий пунктир — водные, охристый пунктир — дополнительные участки. Указаны базы: Сортавала, Петрозаводск, Беломорск и Пяозерский. Линии не повторяют реальные дороги и судовые пути; северные направления — альтернативы, между ними нет общей линии. Поиск, категории и сброс убирают активную схему.
- Адаптивная верстка, на узком экране карта над списком и карточка в нижнем диалоге. Поддержан prefers-reduced-motion.
- Информация о сезонах, бюджете, 40 локальных лицензированных фотографий с атрибуцией.
- Галереи: стрелки, выбор миниатюры, клавиши ←/→ и горизонтальные жесты на сенсорном экране. Автоперелистывания и видео нет. Атрибуция меняется вместе с фотографией.

## Карта и подключение к сети

- В этой версии оставлена только **OpenStreetMap**: HTTPS-тайлы `https://tile.openstreetmap.org/{z}/{x}/{y}.png`. API-ключ не требуется. Светлая подложка, её переключатель и схема без сети полностью удалены.
- Если тайлы не загружаются, показываются сообщение и кнопка «Повторить загрузку карты». Повтор запрашивает тайлы заново. При недоступности сервиса список мест, фотографии, поиск и карточки сохраняются; другой подложки нет.
- Leaflet и модуль группировки включены локально. Все фотографии и данные находятся в проекте. Интернет нужен для картографической подложки и внешних ссылок.
- Тайлы загружаются как изображения; canvas, экспорт карты и внешний fetch для фотографий/контента не используются. CORS-прокси не нужен.
- Для хостинга с CSP разрешите `img-src 'self' data: https://tile.openstreetmap.org`, локальные скрипты и CSS, а также `style-src 'self' 'unsafe-inline'` (Leaflet позиционирует элементы inline).
- Сервис OpenStreetMap остаётся внешним и может быть временно недоступен. Полного офлайн-режима и массовой загрузки тайлов нет. Политика использования: https://operations.osmfoundation.org/policies/tiles/ . Для большого трафика нужен подходящий провайдер.

## Как редактировать

`sources.html` — публичная библиография и примеры программ, `index.html` — страницы и маршруты, `style.css` — оформление, `data.js` — контент и координаты, `app.js` — поиск/карточки/карта, `credits.js` — атрибуция. Поле `sources` — массив объектов `title`, `url`, `publisher`. В каждом месте поле `photos` содержит четыре объекта `src`, `alt`, `caption`, `creditId`; `creditId` ссылается на соответствующую запись в `credits.js`. Чтобы добавить место, дополните массив `window.PLACES`, присвойте уникальные `id`/`n`, положите локальное фото в `assets/images/` и добавьте сведения об авторе в `credits.js`, JSON и страницу атрибуции. Никакого API-ключа в коде нет.

## Масштаб карты

В правой части карты под кнопками +/− находится линейка в метрах или километрах. Её длина и подпись обновляются при изменении масштаба и перемещении карты. Линейка помогает оценить расстояние на местности; длина дороги может быть больше прямого расстояния.
